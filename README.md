# Проект: Автотесты для API Яндекс Самокат

Автотесты для проверки создания заказа и получения его по треку.

## Файлы проекта
- `autotests/configuration.py` — URL сервиса и пути запросов.
- `autotests/data.py` — тела запросов и заголовки.
- `autotests/sender_stand_request.py` — функции отправки запросов.
- `autotests/test_order.py` — автотест (создание заказа + получение по треку).
- `SQL/queries.sql` — SQL-запросы для проверки базы данных.
- `.gitignore` — файлы, которые не нужно отслеживать.

## Как запустить тесты
1. Установить зависимости:
pip install requests pytest

2. Запустить все тесты:
pytest
